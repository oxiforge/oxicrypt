# The C interface at ABI 1: one line per exported function, its parameter
# types and its return type, as `include/oxicrypt.h` declares them, then one
# line per status code the header defines.
#
# Lines may be added at the end: a new function or status code does not
# change the ABI number. A line may never be edited or removed: the first
# lines are frozen, their count and digest recorded in src/abi_tests.rs. A
# change that would alter one (a function removed, a parameter or return type
# changed, a status code renumbered) is a new ABI: raise OXI_ABI_VERSION in
# src/abi_version.rs and start abi/v<number>.txt from the header as it then
# stands.
