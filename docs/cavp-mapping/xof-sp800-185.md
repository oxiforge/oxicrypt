# SP 800-185 derived-function handler-dispatch map

The SP 800-185 derived functions built on cSHAKE: cSHAKE, KMAC,
TupleHash, and ParallelHash, each in a fixed-output form and an
explicit XOF form. All handlers are registered in
`acvp-harness/src/dispatch.rs`.
